# Generated auxiliary visuals

Default to public-web asset search and reuse appropriate supplied brand materials. **Use this generation workflow only when the user explicitly requests AI image generation**, within the requested asset/task scope. Generating a page, adding a background or making a design more complete does not itself request AI-generated imagery. Provider configuration and helper availability do not change this policy. Failed searches must not automatically fall back to image generation; use suitable existing assets or editable native geometry and report missing assets. Honor a later instruction to stop generating or use search.

For explicitly requested generation, prefer backgrounds, restrained texture, small decorative assets, icons or illustrations that serve the content. Authentic product and people photos stay authentic unless the user explicitly asks for a fictional interpretation.

Before each authorized call, state the **purpose → page location → aspect ratio → style**. Plan 0–3 visuals per turn; zero is correct when existing assets and native geometry already serve the page. Do not add decoration to fill a quota. Keep body copy, prices, dates and CTA labels as editable components. Generated text cannot carry key information.

## Gateway helper

When provided by the Gateway, invoke `node .agents/tools/generate-visual.mjs` with stdin JSON:

```json
{
  "requestId": "hero-paper-texture-1",
  "purpose": "Low contrast paper texture behind the hero, below editable text",
  "prompt": "Warm off-white paper grain, very subtle, no text or logo, flat seamless texture",
  "sizeIntent": "landscape",
  "transparent": false
}
```

`sizeIntent` is an intent, mapped only to sizes configured by the service operator. Transparency is sent only when the provider configuration enables the background parameter. The server chooses the model and holds the provider key. Never search for provider credentials or call the provider directly.

At most **three actual calls per turn**, including failures. Reuse the same request ID and identical payload to retrieve an existing result; changing that payload with the same ID is a conflict. Default timeout is 180 seconds. Stopping the turn cancels generation. If the helper is unavailable, generation is disabled; continue with the page's other design work.

The returned object is the `assetManifest` entry. Copy it unchanged and use its `directUrl` in image fields:

```json
{
  "sourceType": "generated",
  "assetId": "gateway-issued-uuid",
  "directUrl": "https://gateway.example/generated-assets/...signed...",
  "contentType": "image/png",
  "width": 1024,
  "height": 1024,
  "format": "png",
  "byteLength": 12345,
  "contentHash": "gateway-issued-sha256",
  "generation": {
    "model": "configured-model",
    "requestId": "hero-paper-texture-1",
    "purpose": "Low contrast paper texture behind the hero, below editable text",
    "prompt": "The actual submitted prompt",
    "createdAt": "2026-10-26T00:00:00.000Z",
    "contentSummary": "Low contrast paper texture"
  }
}
```

This is a shape example, not usable evidence. Real records are checked against Gateway storage and ownership. Do not invent stock-library sources, authors, CC0 or other licenses. Sourced assets still follow verified-image-sources.md; absent sourceType means sourced.

Place generated visuals in supported image fields. For a background or texture, use an `img` below the editable text in z-order. Do not embed temporary generated URLs inside customCSS or rich-text HTML: Apply can replace supported image fields reliably, and rejects final pages retaining temporary links.

## Preview and Apply

Generated PNG/JPEG/WebP files are stored outside the session workspace, with default 24-hour expiry. Signed URLs provide read-only previews; they remain usable after Gateway restart until expiry. Provider URL results are downloaded immediately. Do not download to the workspace or replace the Gateway URL with a local/data/blob URL.

Apply imports generated bytes through DND's existing upload and Media Asset registration flow, then replaces temporary URLs with permanent stored URLs before the canvas commit. Generation and Discard do not register Media Assets. Failed uploads/registration retain completed work for retry. Browser-cached provenance is retained with `originalUrl`; cross-device provenance synchronization is outside this release.

If an optional asset fails, use an existing suitable asset or editable native geometry and report the missing effect. If a key visual explicitly required by the user is missing, say the design is incomplete. A successful compile is not visual approval.
