# Small visual assets

Use native editable rectangles, lines, text and supported patterns for rules, borders, frames, stamps and simple geometric decoration. Search for a separate image only when a subject-specific icon or illustration materially helps the brief.

Follow [asset-workflow.md](asset-workflow.md) for delegation, the shared helper, budgets and fallback. Small graphics share the page budget; they do not start a second workflow or quota. Omit an optional graphic or use native geometry when no suitable candidate fits that budget.

## Prefer adapted sources

Use supplied suitable assets, the configured catalog and cached candidates first. The Gateway helper supports raster candidates from Commons with supported license metadata. A maintained catalog of explicitly licensed compatible assets is preferable to browsing several icon sites for a repeated icon family.

Before manually investigating a provider, check that the exact asset license and file format are accepted by the active compiler. A popular provider or a commercially valid license does not establish compiler support. Do not browse Icons8, Flaticon, unDraw or SVG Repo unless a specific candidate's license is known to fit; never relabel a license to pass compilation. Adding provider support is a separate adapter/contract task.

## Manual candidates

Use [verified-image-sources.md](verified-image-sources.md) for shared evidence and HTTP checks. A detail page and a search thumbnail are not final image URLs. Follow an official file link; do not guess CDN paths. Remote standalone SVG is accepted by the compiler with actual image/svg+xml evidence, but the helper's byte inspection supports PNG/JPEG/WebP only; use the bounded manual workflow for SVG.

Inspect a graphic at its intended size. Keep important words editable; do not place event dates, prices or CTA text only inside an illustration. State missing or visually uninspected assets honestly.
